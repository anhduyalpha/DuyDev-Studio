# Test Engineer Skill
An autonomous, end-to-end unit testing and test coverage specialist designed for Python, TypeScript, and JavaScript projects.
Core methodology:
1. Inspect code & detect framework (vitest / tsc).
2. Design 4-tier test suites (Happy Path, Edge Cases & Boundary Conditions, Nullability & Missing Keys, Error Boundaries).
3. Generate standardized tests (Vitest/Jest).
4. Run & measure deterministic execution.
5. Guarded self-annealing (max 3 iterations).
