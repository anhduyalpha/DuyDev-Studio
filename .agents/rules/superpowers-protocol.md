# Autonomous Superpowers Protocol (Always-On)

1. **The Superpowers Bootstrap (`using-superpowers`)**: Mandatory if $\ge 1\%$ applicable. Process skills first: `systematic-debugging` for bugs, `writing-plans`/`brainstorming` for features.
2. **Systematic Debugging (`systematic-debugging`)**: Iron Law — NO fixes without root-cause investigation. Complete 4 phases: Root Cause $\rightarrow$ Pattern Analysis $\rightarrow$ Hypothesis & Targeted Fix $\rightarrow$ Defense-in-Depth.
3. **Architecture Invariants**: Zero-build Vanilla ES Modules; `StorageManager.sanitizeSafePath()`; atomic sidecars (`.meta.json`/`.thumb.jpg`) in `DriveService`.
4. **Evidence Before Claims (`verification-before-completion`)**: Iron Law — NO claims without fresh terminal evidence in current turn:
   - Frontend: `node --check <file.js>`
   - Backend: `server/node_modules/.bin/tsc.cmd -p server/tsconfig.json --noEmit` & `vitest`
   - Python: `python -m py_compile <file.py>`
5. **Micro-Receipt**: Report exact verification in: `✅ [Verify: <cmd->0> | UI: <ok/n-a> | KI: <ID/none>]`.
