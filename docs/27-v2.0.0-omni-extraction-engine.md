# 27 — v2.0.0 Omni-Extraction Engine & Universal De-cloaking

## 1. Mục tiêu kiến trúc

Nâng cấp extension từ công cụ xuất PDF thông thường thành **Omni-Extraction Engine** với khả năng bẻ gãy mọi rào cản nội dung trên Studocu:
- Không còn bị giới hạn bởi session lưu ngầm trong `localStorage`/`IndexedDB`.
- Bóc sạch hoàn toàn các lớp CSS làm mờ (`filter: blur`) hoặc che khuất (paywall/modals).
- Hỗ trợ tài liệu siêu dài (100–500+ trang) bằng cơ chế Rolling-Window Virtualization.
- Mở rộng hình thức trích xuất sang Markdown sạch cho AI.

## 2. Các cơ chế cốt tử

### Deep Session Sanitization & Anti-Telemetry
- `purgeStudocuStorage()` gọi `chrome.browsingData.remove` xóa toàn bộ `cache`, `indexedDB`, `localStorage` và `serviceWorkers` của các domain Studocu.
- Tự động thiết lập rules `declarativeNetRequest` (Rule ID 101, 102, 103) chặn các network request gửi về `/api/telemetry*`, `/api/logger*`, và `/api/*tracking*`.

### Universal DOM De-cloaking
- `custom_style.css` và `premium_probe.js` triệt tiêu mọi thuộc tính làm mờ `filter: none !important; backdrop-filter: none !important;`.
- Ép hiển thị text layer: `opacity: 1 !important; visibility: visible !important; color: inherit !important; -webkit-text-fill-color: initial !important;`.
- Xóa tự động các node paywall, banner OneTrust, và popup làm phiền khỏi DOM tree.

### Adaptive Rolling-Window Virtualization
- `detectTotalDocumentPages()` đọc chính xác tổng số trang từ metadata `window.__INITIAL_STATE__`, viewer controls (`Page X of Y`), hoặc data attributes.
- `smartScrollToPageIndex(index, totalPages, container)` tự động nội suy tọa độ cuộn, đưa viewport hạ cánh chính xác vào trang cần nạp khi trang bị React unmount.

### Tainted Canvas Fallback
- Khi tài liệu PDF.js vẽ lên `<canvas>` từ ảnh cross-origin CDN dẫn đến lỗi SecurityError khi gọi `toDataURL()`, extension tự động chuyển qua bộ đệm offscreen 2D canvas sạch.

### Trích xuất Markdown thuần (Omni-Extraction)
- Hàm `exportDocumentAsMarkdown()` duyệt qua toàn bộ text layer đã thu thập, định dạng theo chuẩn Markdown phân chia từng trang rõ ràng, tự động đặt tên file theo tiêu đề tài liệu và tải xuống tức thì.
